# 出勤工具 V7.1 独立新版

本版新增在 `attendance_tool_v7_1/`，不覆盖仓库根目录的 `app.py`、旧版 `core/`、`utils/` 或 `attendance_tool_v7_0/`。新版使用自己的 Python 模块，旧应用可以继续作为兜底。

## 上传与独立部署

1. 解压新版 ZIP，得到完整的 `attendance_tool_v7_1` 文件夹。
2. 将这个文件夹新增到原 GitHub 仓库。保留文件夹这一层，不要把其中的 `app.py` 移到仓库根目录；不要直接上传 ZIP 代替源码。
3. 在 Streamlit 创建另一个应用，仓库和分支使用原应用对应的仓库与分支。
4. 新应用的入口填写：`attendance_tool_v7_1/app.py`。给新版单独的应用地址，旧应用的入口和地址保持原样。
5. 新版依赖文件已经随目录提供，本地验收使用 Python 3.12。首次启动下载和加载模型需要时间。
6. 先用同一份成员表、同一批原始截图分别测试新旧应用，检查切图预览、待核对列表与导出结果，再决定日常使用哪个版本。

此次只提供独立代码包，尚未上传 GitHub 或部署线上应用。

## 本版改动

- 游戏截图按实际卡片网格识别，支持不同大小、拼接截图以及最后一页不足整列的情况；避免把空卡槽计为成员。
- YY 先定位成员面板，再定位完整成员行，减少通知区干扰、名字被拆成几块以及漏行。
- 保留原有人工核对、成员匹配、出勤编辑和导出流程。模糊匹配、歧义及低置信度结果仍需核对。
- OCR 模型与主要依赖沿用原代码的配置。本次重点是切图算法升级，没有训练新的文字模型。

算法根据图像内容判断，不按照特定图片文件名或固定成员坐标切图。新的界面、极低清晰度或异常裁剪仍可能需要手动调整；测试通过不代表所有未知图片都能自动识别正确。

## 本地启动

在 `attendance_tool_v7_1` 的上级目录执行：

```powershell
python -m pip install -r attendance_tool_v7_1/requirements.txt
python -m streamlit run attendance_tool_v7_1/app.py
```

## 验收情况

- 15 张真实截图，各自以原尺寸、70%、130%进行切框回归，共 45 项；检查完整姓名区域、卡片边界、重叠、空位和通知区，而非仅比较数量。
- 4 项成员匹配及失败处理回归，总计 49 项测试通过。
- Streamlit AppTest 入口启动通过。
- 实际调用原配置的 OCR 模型读取 2 个 YY 行裁图及 2 个游戏卡片，均成功返回文字。这是调用链验证，不是所有成员姓名的准确率评测。

测试命令（同样从上级目录执行）：

```powershell
python -m unittest attendance_tool_v7_1.tests.test_regression -v
```

`tests/` 内含回归截图，仅用于复现测试；不包含成员数据库、凭据或模型权重。
